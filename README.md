# Nebula

Nebula is a real hardware and software project.

This repository is split into focused branches so electrical engineering and software development can move independently while sharing a common architecture and requirements model.

## Branches

- HARDWARE — PCB, power, RF, mechanical, BOM, validation
- SOFTWARE — firmware, operating-system architecture, services, testing
- main — project coordination, shared engineering rules, CI, and AI collaboration

## Engineering principle

Do not turn assumptions into facts. Record requirements, decisions, part numbers, measurements, and test results in version control.

## Current stage

Early architecture and platform research.
