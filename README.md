# Nebula Hardware

Nebula is a real hardware/software project. This branch is the hardware workspace for the custom-board effort.

## Scope

- Custom PCB design
- Compute, memory, and storage
- Power and charging
- Cellular / Wi-Fi / Bluetooth / GNSS
- Display and touch
- Cameras, sensors, and audio
- USB-C and other I/O
- Thermal and mechanical integration
- Firmware and hardware validation

## Engineering rule

The first revision will use commercially available, documented components. Nebula is not attempting to fabricate a smartphone-class semiconductor from scratch.

## Workspace

- `docs/` — architecture, requirements, and roadmap
- `schematics/` — schematic sources and exports
- `pcb/` — PCB design sources and manufacturing files
- `firmware/` — low-level board firmware
- `mechanical/` — enclosure and mechanical CAD
- `bom/` — bill of materials
- `validation/` — bring-up and test documentation
- `AI/` — shared AI handoff notes

## Status

Early requirements / architecture stage.
