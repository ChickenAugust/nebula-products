# Nebula Software

Nebula Software is the software stack that runs above the custom hardware.

## Layers

- Boot and board support
- Low-level firmware
- Kernel / operating system
- Device services
- Hardware abstraction
- System UI
- Applications
- Update and recovery
- Diagnostics and logging

## Current stage

Architecture and development scaffolding. Hardware-dependent implementations remain gated on the selected compute platform.

## Repository relationship

The HARDWARE branch contains electrical and mechanical design. This branch owns the software architecture and software implementation.
