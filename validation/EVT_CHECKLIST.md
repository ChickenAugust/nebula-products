# Nebula EVT Bring-Up Checklist

## Before power

- Inspect PCB assembly
- Verify component orientation
- Check for shorts on major rails
- Confirm connector placement
- Verify programming/debug access

## First power

- Current-limit the lab supply
- Measure input voltage
- Verify each expected rail
- Check sequencing
- Check standby current

## Boot

- Confirm debug console
- Confirm boot ROM / bootloader behavior
- Confirm storage detection
- Confirm memory initialization
- Record firmware and hardware revision

## Peripheral validation

- USB-C
- Display / touch
- Audio
- Cameras
- Wi-Fi / Bluetooth
- Other radio interfaces
- Sensors

## Thermal

- Record idle temperature
- Record sustained-load temperature
- Identify unexpected hot spots

## Result

Record Pass / Fail / Blocked plus measured values in a dated test report.
