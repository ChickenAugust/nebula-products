# Nebula Agent Instructions

Treat the repository as the source of truth.

Read the relevant specification, architecture, requirements, decisions, and AI handoff files before changing implementation.

Never invent hardware parts, pinouts, measurements, interfaces, test results, or completion status.

When hardware is involved, use exact manufacturer part numbers and document the source.

Keep platform-specific code isolated from portable services.

When changing an accepted requirement or architecture decision, update the relevant decision record.

Prefer small, reviewable commits with descriptive messages.

Unknowns should be marked TBD instead of guessed.
