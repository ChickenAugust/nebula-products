# Nebula Development Workflow

## 1. Define

Capture the user-visible requirement and engineering constraints.

## 2. Decide

Record architecture decisions and alternatives.

## 3. Implement

Make the smallest change that moves the system forward.

## 4. Validate

Run software tests or hardware validation appropriate to the layer.

## 5. Record

Update status, measurements, revisions, and follow-up work.

## AI collaboration

ChatGPT and GitHub Copilot should use the repository files as their shared project state. Repository-wide Copilot instructions are stored in .github/copilot-instructions.md, and project context is maintained in AI/HANDOFF.md files.
