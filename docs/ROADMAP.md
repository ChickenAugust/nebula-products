# Nebula Hardware Roadmap

## Phase 0 — Requirements
- Define target device and physical dimensions
- Define performance targets
- Define display and touch requirements
- Define connectivity requirements
- Define battery and charging targets
- Define camera, audio, and sensor requirements
- Define manufacturing constraints

## Phase 1 — Component architecture
- Select compute platform
- Select RAM and storage
- Select PMIC and charging solution
- Select connectivity components
- Select display/touch interface
- Select audio architecture
- Select sensors
- Create preliminary block diagram
- Start preliminary BOM

## Phase 2 — Schematic
- Capture complete schematics
- Define the power tree
- Define clocks, reset, and boot
- Define high-speed interfaces
- Add test points
- Review schematics

## Phase 3 — PCB
- Define stack-up
- Place major components
- Route power and high-speed buses
- Route RF according to component requirements
- Complete DRC and manufacturing checks

## Phase 4 — EVT bring-up
- Manufacture first boards
- Inspect assembly
- Validate power rails and boot
- Validate memory and storage
- Validate display/touch and USB-C
- Validate connectivity
- Record failures and fixes

## Phase 5 — DVT / PVT
- Thermal validation
- RF validation
- Mechanical validation
- Reliability testing
- Manufacturing optimization
- Production documentation
