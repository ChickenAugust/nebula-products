# Nebula Repository Map

## main
Project coordination, common rules, CI, agent instructions, and cross-layer architecture.

## HARDWARE
Custom board engineering:
- motherboard
- power
- RF
- schematics
- PCB
- mechanical
- BOM
- validation

## SOFTWARE
Software stack:
- firmware
- operating system
- system services
- update/recovery
- tests

## Shared concept

The branches are separate workspaces, but requirements and architectural decisions should stay aligned. When a cross-layer change is made, update documentation on both sides.
