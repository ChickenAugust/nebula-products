# Nebula Hardware Decisions

## D-001 — Custom PCB direction
Status: Accepted

Nebula will use a custom PCB rather than assembling the product from phone motherboards.

Reason: A custom board gives the project control over electrical architecture, interfaces, physical layout, and future revisions.

## D-002 — First silicon strategy
Status: Accepted

The first hardware revision will use commercially available compute and supporting ICs rather than attempting to create a smartphone-class SoC.

Reason: Advanced silicon design and fabrication is a separate semiconductor program with substantially different tooling, cost, and timescale.

## D-003 — Requirements before layout
Status: Accepted

System requirements and a preliminary component architecture must be established before final PCB layout.

Reason: Late changes to compute, memory, power, display, or RF architecture can invalidate board layout.
