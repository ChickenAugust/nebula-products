# Nebula Specification

Draft v0.1.

## Product
A custom computing device built around a custom PCB and a dedicated software stack.

## Required system properties
- Custom main board
- USB-C
- Rechargeable battery
- Display and touch
- Wireless connectivity
- Storage
- Secure boot / trusted software chain where hardware supports it
- Recoverable software updates
- Hardware and software revision tracking

## Unresolved product decisions
- Exact device category
- Final dimensions
- Compute platform
- RAM and storage capacity
- Cellular support and target regions
- Camera configuration
- Audio configuration
- Battery capacity
- Industrial design

Unresolved items remain TBD until explicitly accepted.
